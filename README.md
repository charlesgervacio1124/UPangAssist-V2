# UPang Assist

UPang Assist provides a student-facing campus assistant backed by a Node.js API.

## Applications

| Application | Directory | Description |
| :--- | :--- | :--- |
| **Student Assistant** | `my-react-app` | Interactive campus assistant for students and faculty |
| **Backend API** | `server` | Node.js Express server and MongoDB API |

---

## Quick Start Commands

From the root project directory:

```bash
# Start the Student Assistant
npm run dev:student

# Start the Backend API
npm run dev:server
```

Build the Student Assistant with:

```bash
npm run build:student
```
